## 2. Definiciones

- **"API"**: Esta interfaz de programación de aplicaciones y todos sus componentes
- **"Usuario"**: Cualquier persona u organización que acceda o utilice la API
- **"Contenido"**: Todos los datos transmitidos a través de la API
- **"Servicio"**: La API, documentación, y servicios relacionados
- **"Nosotros/Nuestro"**: Los operadores del Servicio

## 3. Descripción del Servicio

La API proporciona funcionalidad para:

- Gestionar campañas y datos asociados
- Almacenar información de entidades (personajes, ubicaciones, eventos, etc.)
- Realizar búsquedas y consultas
- Acceder a información contextual

El Servicio se proporciona "tal como está" sin garantías adicionales.

## 4. Uso Aceptable

### 4.1 Usos Permitidos

Puedes utilizar la API para:

- Propósitos legales y legítimos
- Uso personal y empresarial
- Desarrollo, pruebas y producción
- Análisis y reportes internos

### 4.2 Usos Prohibidos

**No debes**:

- Violar leyes o regulaciones aplicables
- Acceder sin autorización o de forma fraudulenta
- Realizar ataques de negación de servicio (DoS/DDoS)
- Implementar scraping excesivo o harvesting de datos
- Interrumpir o interferir con la operación del Servicio
- Intentar obtener acceso no autorizado
- Reproducir, duplicar, copiar o reutilizar código sin licencia
- Transmitir malware, virus o código malicioso
- Usar con fines de discriminación, acoso o ilegalidad
- Revelar información confidencial de otros usuarios
- Infringir derechos de propiedad intelectual

### 4.3 Rate Limiting

Nos reservamos el derecho a:

- Limitar solicitudes (rate limiting)
- Establecer cuotas de uso
- Suspender acceso por violaciones

Los límites actuales:

- **Por defecto**: 100 solicitudes por minuto
- **Máximo de conexiones concurrentes**: 10
- **Tamaño máximo de payload**: 30 MB
